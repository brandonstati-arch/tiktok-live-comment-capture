Campos capturados

Cada comentario se guarda con 26 columnas: hora exacta de publicación (con milisegundos, tomada del servidor de TikTok), fecha, hora, timestamp Unix, latencia de recepción, usuario, nombre visible, ID del autor, Sec UID, texto del comentario, idioma, ID del mensaje, rol (moderador / suscriptor / seguidor / seguimiento mutuo / amigo / top gifter), niveles de miembro y de gifter, insignias, menciones, enlace al perfil y sala.

Aviso legal. Los nombres de usuario y comentarios son datos personales (RGPD en la UE y normativa equivalente en otros países). Necesitas una base legal para tratarlos y publicarlos. El chat de un directo no se guarda en TikTok: lo que no captures en directo se pierde. La captura se apoya en el WebSocket interno de TikTok, que sus términos de servicio no contemplan como vía oficial; el riesgo real es el bloqueo temporal de IP o cuenta. La firma de conexión la provee Euler Stream (tier comunitario gratuito).

Los datos se guardan en la carpeta sesiones/ de este proyecto: un .csv que se escribe en vivo (a prueba de cortes) y un .xlsx final.
